# OpticClient

![OpticClient Logo](assets/opticclient-logo.svg)

OpticClient is a lightweight Minecraft client focused on PvP improvements, customizable HUD elements, and a clean in-game interface.

It provides useful gameplay information while keeping the screen organized and easy to read.

## Features

- Customizable HUD
- FPS counter
- Coordinates display
- Armor durability display
- Potion and status-effect display
- Toggle Sprint
- No Hurt Cam
- Customizable crosshair
- In-game configuration menu
- Clean and lightweight design

OpticClient is designed for players who want a simple and practical PvP client with useful visual features and minimal screen clutter.

## Client-Side

OpticClient is a client-side mod. It does not need to be installed on the server and mainly provides visual improvements, HUD features, and quality-of-life options.
